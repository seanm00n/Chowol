<a name="game-description"></a>
## 🕹️ Game Description

**Chowol** is a puzzle simulation game inspired by the **Transcendence system** from the MMORPG **Lost Ark**.

Players select an equipment slot and transcendence stage, then strategically use cards and special tiles to destroy all tiles on the board.

---

<a name="game-features"></a>
## ⭐ Game Features

| Feature | Description |
|------|------|
| 🧩 Tile-based Puzzle System | A strategic puzzle played on a tile board where players destroy tiles using card effects. |
| 🃏 Card Strategy System | Different card types and ranks change the destruction range and effects, creating strategic gameplay. |
| ✨ Special Tile Effects | Certain tiles trigger special effects such as card upgrades or duplication, altering the flow of the game. |
| 🎯 Probability-based Gameplay | Card effects and tile destruction involve probability, resulting in different outcomes each playthrough. |

<a name="tech-stack"></a>
## 🛠️ Tech Stack

- **Unity Engine**: Tile-based puzzle gameplay implementation, scene management  
- **Unity UI / Event System**: Card UI and tile interaction handling  
- **Unity Audio System**: Event-based sound playback  
- **C#**: Game state management using a GameManager architecture, card system, tile logic implementation  
- **Data Structures**: Array, List, Dictionary, HashSet, Enum, LINQ  
- **Design Pattern**: Singleton pattern for global data management  
- **Git**: Version control
